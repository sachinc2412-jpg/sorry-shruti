# For Shruti

A painted rainy-room website from Aditya. Wipe the foggy glass to reveal the message and unlock the handwritten note.

## Deployment

Deploy the repository root on Vercel as Other / static. No install command or build step is required.

## Files

- index.html: room and note
- style.css: responsive layout and high-contrast lettering
- script.js: fog wiping, rain, steam and controls
- assets/: desktop and mobile artwork
